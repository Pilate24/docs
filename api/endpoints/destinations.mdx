The Destinations API gives you access to GlobeTrotter's curated catalogue of 20+ global cities. Use it to search, filter, and retrieve destination details including available activities. Both endpoints are **publicly readable** — no authentication is required to browse the catalogue. You only need a session when adding a destination to a trip stop.

<Note>
  Destination IDs returned by this API are used as the `destinationId` field when creating trip stops via `POST /api/trips/:tripId/stops`.
</Note>

---

## GET /api/destinations

Return a paginated list of destinations from the GlobeTrotter catalogue. Filter by continent or cost tier, search by city or country name, and sort the results to suit your use case.

**Authentication:** Not required — this endpoint is public.

### Query parameters

<ParamField query="search" type="string">
  Full-text search string matched against city name, country name, and destination description. Case-insensitive. Example: `"tokyo"` or `"south america"`.
</ParamField>

<ParamField query="continent" type="string">
  Filter by geographic continent. Accepted values: `Africa` | `Asia` | `Europe` | `North America` | `South America` | `Oceania`.
</ParamField>

<ParamField query="costIndex" type="string">
  Filter by destination cost tier. Accepted values:
  - `BUDGET` — typically under $80/day
  - `MODERATE` — typically $80–$200/day
  - `LUXURY` — typically over $200/day
</ParamField>

<ParamField query="sort" type="string">
  Sort the returned list. Accepted values: `popularity` (default) | `cost` | `name`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of destinations to return per page. Defaults to `20`. Maximum `100`.
</ParamField>

<ParamField query="offset" type="integer">
  Number of destinations to skip for pagination. Defaults to `0`. Use `offset=20` to fetch the second page when `limit=20`.
</ParamField>

### Response fields

<ResponseField name="data" type="array">
  Array of destination summary objects.

  <Expandable title="Destination object fields">
    <ResponseField name="id" type="string">
      UUID of the destination. Use this value as `destinationId` when adding a stop to a trip.
    </ResponseField>
    <ResponseField name="name" type="string">
      City name, e.g. `"Tokyo"`.
    </ResponseField>
    <ResponseField name="country" type="string">
      Country the city is located in, e.g. `"Japan"`.
    </ResponseField>
    <ResponseField name="continent" type="string">
      Geographic continent the destination belongs to.
    </ResponseField>
    <ResponseField name="costIndex" type="string">
      Cost tier: `BUDGET` | `MODERATE` | `LUXURY`.
    </ResponseField>
    <ResponseField name="popularityScore" type="number">
      Integer popularity score from 1–10 based on traveller activity within GlobeTrotter.
    </ResponseField>
    <ResponseField name="avgDailyCost" type="number">
      Estimated average daily spend in USD, including accommodation, food, and typical activities.
    </ResponseField>
    <ResponseField name="imageUrl" type="string">
      URL of the destination's hero image.
    </ResponseField>
    <ResponseField name="lat" type="number">
      Geographic latitude — used to render the destination on the interactive map.
    </ResponseField>
    <ResponseField name="long" type="number">
      Geographic longitude — used to render the destination on the interactive map.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example request

```http title="Search for budget destinations in Asia"
GET /api/destinations?continent=Asia&costIndex=BUDGET&sort=popularity&limit=10
```

### Pagination example

```http title="Fetch second page (destinations 21–40)"
GET /api/destinations?limit=20&offset=20
```

<Tip>
  Combine `search` with `continent` for faster, more targeted results. For example, searching `"garden"` with `continent=Europe` returns European cities with "garden" in their name or description.
</Tip>

## GET /api/destinations/:id

Retrieve a single destination by its UUID, including the full catalogue of activities available at that city. Use the returned `activities` array to choose which activities to schedule when building a trip stop.

**Authentication:** Not required — this endpoint is public.

### Path parameters

<ParamField path="id" type="string" required>
  UUID of the destination to retrieve.
</ParamField>

### Response fields

<ResponseField name="data" type="object">
  Full destination object with nested activities.

  <Expandable title="Destination detail fields">
    <ResponseField name="id" type="string">Destination UUID.</ResponseField>
    <ResponseField name="name" type="string">City name.</ResponseField>
    <ResponseField name="country" type="string">Country name.</ResponseField>
    <ResponseField name="continent" type="string">Geographic continent.</ResponseField>
    <ResponseField name="costIndex" type="string">`BUDGET` | `MODERATE` | `LUXURY`.</ResponseField>
    <ResponseField name="popularityScore" type="number">Popularity score 1–10.</ResponseField>
    <ResponseField name="avgDailyCost" type="number">Average daily cost estimate in USD.</ResponseField>
    <ResponseField name="description" type="string">Full destination description and travel highlights.</ResponseField>
    <ResponseField name="imageUrl" type="string">URL of the destination's hero image.</ResponseField>
    <ResponseField name="lat" type="number">Latitude for map rendering.</ResponseField>
    <ResponseField name="long" type="number">Longitude for map rendering.</ResponseField>
    <ResponseField name="activities" type="array">
      Array of all activities available at this destination.

      <Expandable title="Activity object fields">
        <ResponseField name="id" type="string">
          Activity UUID. Use this as `activityId` when scheduling an activity to a stop.
        </ResponseField>
        <ResponseField name="title" type="string">
          Activity name, e.g. `"Senso-ji Temple Visit"`.
        </ResponseField>
        <ResponseField name="category" type="string">
          Activity type: `SIGHTSEEING` | `ADVENTURE` | `FOOD` | `CULTURE` | `RELAXATION` | `NIGHTLIFE`.
        </ResponseField>
        <ResponseField name="estimatedCost" type="number">
          Estimated cost per person in USD. `0` for free entry.
        </ResponseField>
        <ResponseField name="durationMinutes" type="number">
          Estimated duration of the activity in minutes.
        </ResponseField>
        <ResponseField name="rating" type="number">
          Average traveller rating out of 5.0, e.g. `4.8`.
        </ResponseField>
        <ResponseField name="imageUrl" type="string">
          Optional URL of the activity's thumbnail image.
        </ResponseField>
        <ResponseField name="description" type="string">
          Brief description of what the activity entails.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Accordion title="Activity categories reference">
  Activities at each destination are tagged with one of six categories used for filtering and icon display throughout the app:

  | Category | Description |
  |----------|-------------|
  | `SIGHTSEEING` | Landmark visits, viewpoints, and scenic spots |
  | `ADVENTURE` | Outdoor activities, sports, and physical experiences |
  | `FOOD` | Restaurants, markets, food tours, and culinary experiences |
  | `CULTURE` | Museums, temples, galleries, and historical sites |
  | `RELAXATION` | Spas, beaches, parks, and leisurely pursuits |
  | `NIGHTLIFE` | Bars, clubs, evening entertainment, and night tours |
</Accordion>
