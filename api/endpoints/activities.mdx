The Activities API provides access to GlobeTrotter's curated catalogue of activities across destinations worldwide. Activities are linked to specific destinations and can be filtered by category, cost, and duration — making it easy to discover what's available at each stop in your itinerary before you commit to a schedule. This endpoint is publicly accessible; no authentication is required to browse or filter activities.

## GET /api/activities

List and search activities from the global catalogue. Filter by destination, category, cost ceiling, or duration to narrow results before scheduling them to a trip stop.

**Authentication:** Not required — this endpoint is public.

### Query parameters

<ParamField query="destinationId" type="string">
  Filter activities to a specific destination. Pass the destination's UUID to scope results to a single city. Destination UUIDs are returned by `GET /api/destinations`.
</ParamField>

<ParamField query="category" type="string">
  Filter by activity category. Accepted values: `SIGHTSEEING` | `ADVENTURE` | `FOOD` | `CULTURE` | `RELAXATION` | `NIGHTLIFE`.
</ParamField>

<ParamField query="search" type="string">
  Keyword search against activity titles. Partial matches are supported — for example, `"food"` returns `"Street Food Tour"` and `"Food Market Walk"`.
</ParamField>

<ParamField query="maxCost" type="number">
  Return only activities with an `estimatedCost` at or below this value. Costs are expressed in USD.
</ParamField>

<ParamField query="maxDuration" type="integer">
  Return only activities with a `durationMinutes` value at or below this threshold.
</ParamField>

<ParamField query="sort" type="string">
  Sort the result set. Accepted values: `rating` (highest first), `cost` (lowest first), `duration` (shortest first). Defaults to `rating` when omitted.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Maximum number of activities to return per page.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip before returning results. Use with `limit` to paginate through large result sets.
</ParamField>

### Response fields

<ResponseField name="data" type="array">
  Array of activity objects matching the query filters.

  <Expandable title="Activity object fields">
    <ResponseField name="id" type="string">
      Activity UUID. Pass this as `activityId` when scheduling the activity to a stop via `POST /api/trips/:tripId/stops/:stopId/activities`.
    </ResponseField>
    <ResponseField name="destinationId" type="string">
      UUID of the destination this activity belongs to.
    </ResponseField>
    <ResponseField name="title" type="string">
      Activity name, e.g. `"Street Food Tour in Shibuya"`.
    </ResponseField>
    <ResponseField name="category" type="string">
      Activity category: `SIGHTSEEING` | `ADVENTURE` | `FOOD` | `CULTURE` | `RELAXATION` | `NIGHTLIFE`.
    </ResponseField>
    <ResponseField name="estimatedCost" type="number">
      Estimated cost per person in USD. `0` for free activities.
    </ResponseField>
    <ResponseField name="durationMinutes" type="number">
      Estimated duration of the activity in minutes.
    </ResponseField>
    <ResponseField name="rating" type="number">
      Average traveller rating out of 5.0.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example request

```http title="Find top-rated culinary activities under $60 at a destination"
GET /api/activities?destinationId=dest-uuid&category=FOOD&maxCost=60&sort=rating&limit=5
```

### Example response

```json title="200 OK"
{
  "success": true,
  "data": [
    {
      "id": "act-uuid",
      "destinationId": "dest-uuid",
      "title": "Street Food Tour in Shibuya",
      "category": "FOOD",
      "estimatedCost": 45,
      "durationMinutes": 180,
      "rating": 4.7
    }
  ],
  "message": "Activities retrieved successfully",
  "error": null
}
```

<Note>
  To schedule an activity to a trip stop, use `POST /api/trips/:tripId/stops/:stopId/activities` with the `activityId` from this response. The Activities API is read-only — it only supports discovery and filtering.
</Note>

### Response codes

| Status | Meaning |
|--------|---------|
| `200`  | Success — returns an array of matching activities (empty array if none match) |
| `400`  | Invalid query parameter value (e.g. unrecognised `category` or non-numeric `maxCost`) |
| `500`  | Internal server error |

### Pagination pattern

Combine `limit` and `offset` to page through the full catalogue:

```http title="Page through the activity catalogue"
# Page 1 — first 20 results
GET /api/activities?limit=20&offset=0

# Page 2 — next 20 results
GET /api/activities?limit=20&offset=20
```

<Tip>
  Pair `destinationId` with `sort=rating` to surface the highest-rated things to do at a specific stop before you lock in your itinerary dates.
</Tip>
