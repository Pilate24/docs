The Budget API returns a complete financial breakdown for a trip — aggregated costs by category, a day-by-day burn rate, variance against your target spend, and a daily average. Use it to power dashboards, build spend-tracking views, or let travelers know at a glance whether they're within budget.

## GET /api/trips/:tripId/budget

Fetch the full budget analysis for a single trip. This endpoint requires authentication and trip ownership — you can only retrieve budget data for trips that belong to your account.

### Path parameters

<ParamField path="tripId" type="string" required>
  The UUID of the trip whose budget you want to retrieve.
</ParamField>

### Example request

```http title="Fetch budget breakdown for a trip"
GET /api/trips/trip-uuid/budget
```

### Response fields

<ResponseField name="targetBudget" type="number">
  The budget goal set when the trip was created or last updated, expressed in the trip's configured currency (default `USD`).
</ResponseField>

<ResponseField name="totalEstimatedCost" type="number">
  The sum of all estimated costs across every category — lodging, transport, activities, and food — for the entire trip duration.
</ResponseField>

<ResponseField name="variance" type="number">
  `targetBudget` minus `totalEstimatedCost`. A **positive** value means you are under budget (money remaining). A **negative** value means you have exceeded your target spend.
</ResponseField>

<ResponseField name="dailyAverage" type="number">
  `totalEstimatedCost` divided by the total number of trip days. Useful for comparing spend efficiency across trips of different lengths.
</ResponseField>

<ResponseField name="breakdown" type="object">
  Category-level cost totals aggregated across all stops.

  <ResponseField name="breakdown.lodging" type="number">
    Total accommodation costs across all trip stops. Calculated as `accommodationCost × numberOfNights` for each stop, where `accommodationCost` is the per-night rate entered on the stop.
  </ResponseField>

  <ResponseField name="breakdown.transport" type="number">
    Total transport costs (flights, trains, buses, etc.) across all stop transitions. Derived from the `transportCost` field on each stop.
  </ResponseField>

  <ResponseField name="breakdown.activities" type="number">
    Sum of costs for all scheduled activities. Uses `customCost` when set on a scheduled activity, otherwise falls back to the catalogue `estimatedCost`.
  </ResponseField>

  <ResponseField name="breakdown.food" type="number">
    Estimated food and dining spend for the trip duration. Calculated as **$50 per person per day** across all stop days — adjust individual stop dates to influence this figure.
  </ResponseField>
</ResponseField>

<ResponseField name="dailyBurnRate" type="array">
  An ordered array of per-day spend objects covering every calendar day of the trip.

  <ResponseField name="dailyBurnRate[].date" type="string">
    ISO 8601 date string (`YYYY-MM-DD`) representing the day.
  </ResponseField>

  <ResponseField name="dailyBurnRate[].amount" type="number">
    Estimated total spend attributed to that specific day.
  </ResponseField>
</ResponseField>

### Example response

```json title="200 OK"
{
  "success": true,
  "data": {
    "targetBudget": 4000,
    "totalEstimatedCost": 3650,
    "variance": 350,
    "dailyAverage": 260,
    "breakdown": {
      "lodging": 1200,
      "transport": 800,
      "activities": 450,
      "food": 1200
    },
    "dailyBurnRate": [
      { "date": "2026-06-01", "amount": 310 },
      { "date": "2026-06-02", "amount": 280 }
    ]
  },
  "message": "Budget retrieved successfully",
  "error": null
}
```

<Tip>
  A positive `variance` means you are under budget — there is money left to spend. A negative `variance` (e.g. `-500`) means you are $500 over your target. Review the `dailyBurnRate` array to identify high-spend days and adjust accommodation or activity costs at those stops.
</Tip>

### Response codes

| Status | Meaning |
|--------|---------|
| `200`  | Success — returns the full budget summary object |
| `401`  | Not authenticated — a valid session is required |
| `403`  | Authenticated but you do not own this trip |
| `404`  | No trip found with the given `tripId` |
| `500`  | Internal server error |

### Budget categories explained

<Accordion title="Lodging">
  Accommodation costs entered per stop via the `accommodationCost` field. This is a **nightly rate** — the budget engine multiplies it by the number of nights at that stop to compute the total lodging contribution. For a stop with `accommodationCost: 120` and a 4-night stay, the lodging contribution is `$480`.
</Accordion>

<Accordion title="Transport">
  Travel costs between stops, derived from the `transportCost` field on each stop. Covers all transport modes: `FLIGHT`, `TRAIN`, `BUS`, `DRIVE`, `FERRY`, and `NONE`.
</Accordion>

<Accordion title="Activities">
  Aggregated costs from all activities scheduled to stops on this trip. If a `customCost` override was set when scheduling an activity, that value is used instead of the catalogue price.
</Accordion>

<Accordion title="Food">
  Food and dining costs are estimated at a flat **$50 per day** for each day covered by a trip stop. This default gives a baseline food budget you can compare against actual spend. The `dailyAverage` field incorporates this estimate alongside all other cost categories.
</Accordion>
