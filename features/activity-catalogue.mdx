The Activity Catalogue gives you access to a curated library of activities across all destinations in GlobeTrotter — filterable by category, destination, and maximum cost — and lets you schedule any activity directly to a city stop in your itinerary. Whether you are hunting for a hidden culinary experience in Tokyo or an adrenaline-fuelled adventure in Queenstown, the catalogue surfaces the right options and wires them into your trip budget the moment you confirm.

## Accessing the Catalogue

You can reach the Activity Catalogue from two entry points:

<CardGroup cols={2}>
  <Card title="Explore Menu" icon="compass">
    In the left sidebar, navigate to **Explore → Activities** to browse the full catalogue independent of any trip.
  </Card>
  <Card title="Itinerary Builder" icon="calendar-days">
    Inside any trip, open the **Builder** tab, locate a city stop, and click **Select Activities** to browse activities pre-filtered for that destination.
  </Card>
</CardGroup>

## Browsing and Filtering Activities

The catalogue gives you two independent filters that stack together to narrow results in real time.

**Category filter** — select a category from the dropdown to show only activities of that type:

| Category Value | Activity Type |
|---|---|
| `SIGHTSEEING` | Landmarks, monuments, observation decks, audio-guided tours |
| `ADVENTURE` | Hiking, water sports, climbing, extreme activities |
| `FOOD` | Food tours, cooking classes, wine tastings, culinary experiences |
| `CULTURE` | Museums, heritage sites, local ceremonies, art galleries |
| `NIGHTLIFE` | Bar crawls, live music, rooftop experiences, clubs |

Select **All** (the default) to see activities across every category.

**Max Cost filter** — enter a maximum estimated cost in your trip's currency. The catalogue hides any activity whose estimated cost exceeds the value you enter.

## Activity Card Details

Each card in the catalogue displays at a glance:

- **Title** — the activity name
- **Description** — a short summary of what the activity involves
- **Category** — a colour-coded badge matching the category filter
- **Estimated Cost** — the catalogue default price in USD
- **Duration** — estimated time to complete the activity, in minutes
- **Star Rating** — average user rating from 1–5

## Scheduling an Activity

<Steps>
  <Step title="Find the activity you want">
    Use the category filter and max cost input to locate the activity. Confirm the estimated cost and duration suit your plan.
  </Step>
  <Step title="Click Schedule">
    On the activity card, click the **Schedule** button. GlobeTrotter assigns the activity to the current city stop.
  </Step>
  <Step title="Review in the Builder">
    The activity appears immediately as a chip on the stop card in the Itinerary Builder. Its estimated cost is rolled into the trip budget total straight away.
  </Step>
</Steps>

## Viewing Scheduled Activities

Once scheduled, activities surface in two places:

- **Itinerary Builder (Builder tab)** — activities appear as colour-coded chips on each city stop card.
- **Calendar Timeline (Calendar tab)** — activities appear as entries on their scheduled dates alongside city stay spans.

## Removing an Activity

To remove a scheduled activity from a stop, use one of these methods:

- **In the Itinerary Builder** — click the **❌** icon on the activity chip attached to the stop card.
- **Via the API** — send a `DELETE` request to the activity endpoint:

```http
DELETE /api/trips/:tripId/stops/:stopId/activities/:id
```

**Response:**

```json
{
  "success": true,
  "data": null,
  "message": "Activity removed from stop.",
  "error": null
}
```

## Adding an Activity via API

You can also add an activity to a stop programmatically:

```http
POST /api/trips/:tripId/stops/:stopId/activities
```

```json
{
  "activityId": "act_001",
  "estimatedCost": 32
}
```

**Response:**

```json
{
  "success": true,
  "data": {
    "id": "scheduled_abc",
    "tripId": "trip_123",
    "stopId": "stop_456",
    "activityId": "act_001",
    "estimatedCost": 32
  },
  "message": "Activity added to stop.",
  "error": null
}
```

<Tip>
  When you have a specific booking quote that differs from the catalogue estimate — for example, a private guided tour you have already reserved — pass the actual price as `estimatedCost` in the API request to keep your budget projection accurate from the moment you confirm.
</Tip>

## Activity Fields Reference

| Field | Description |
|---|---|
| `title` | Activity name as listed in the catalogue |
| `category` | Type of activity: `SIGHTSEEING`, `ADVENTURE`, `FOOD`, `CULTURE`, or `NIGHTLIFE` |
| `estimatedCost` | Catalogue default price in USD |
| `durationMinutes` | Estimated time to complete the activity, in minutes |
| `rating` | Average user rating on a 1–5 scale |
| `description` | Short description of the activity |
