GlobeTrotter ships with two pre-seeded demo accounts — a regular traveler account and an admin account — so you can explore every feature without creating a new account. Each demo account comes pre-loaded with sample trips, stops, and activities so you can immediately interact with real data in the Itinerary Builder, Budget tracker, Calendar view, and Public Sharing features.

## Demo Accounts

| Account | Email | Password | Role | Access |
|---|---|---|---|---|
| Demo Traveler | `user@globetrotter.com` | `password123` | USER | Full trip planning, discovery, and public trip sharing |
| Demo Admin | `admin@globetrotter.com` | `password123` | ADMIN | All USER features plus the admin analytics dashboard at `/admin` |

## Using Demo Login

<Steps>
  <Step title="Go to /login">
    Open `/login` in your browser. Alongside the standard sign-in form you will see two one-click demo login buttons at the bottom of the page.
  </Step>
  <Step title="Click a demo login button">
    - Click **1-Click Demo Traveler Login** to sign in as `user@globetrotter.com` (USER role).
    - Click **1-Click Admin Demo Login** to sign in as `admin@globetrotter.com` (ADMIN role).

    No form filling is required — the credentials are submitted automatically.
  </Step>
  <Step title="Explore the platform">
    You are logged in immediately and redirected to `/dashboard`. The demo account is pre-loaded with sample data — start exploring right away.
  </Step>
</Steps>

<Warning>
  Demo accounts are **shared across all users**. Do not store sensitive personal information, real travel plans, or private data in demo trips. Demo data may be reset periodically without notice — any changes you make to demo accounts will not be preserved.
</Warning>

## Admin Demo: Analytics Dashboard

<Tip>
  Use the **Admin demo account** (`admin@globetrotter.com`) to explore the analytics dashboard at `/admin`. It displays platform-wide KPIs — total users and trips, signup trends over time, and the top destinations by trip volume — visualized with interactive charts. This view is only accessible to accounts with the ADMIN role.
</Tip>
